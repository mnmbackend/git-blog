# Hissa qo'shish bo'yicha qo'llanma

Ushbu repo `mnmbackend/git-blog`da fikrlar, tajriba va kundalik qarashlar haqida maqolalar saqlanadi. Agar siz ham maqola yozmoqchi bo'lsangiz, mavjud yozuvlarni yaxshilamoqchi bo'lsangiz yoki xatolarni tuzatmoqchi bo'lsangiz, quyidagi qoidalar asosida hissa qo'shishingiz mumkin.

## Qanday hissa qo'shish mumkin?

- Yangi maqola qo'shish
- Mavjud maqolani to'g'rilash yoki kengaytirish
- Imlo, grammatik yoki uslubiy xatolarni tuzatish
- Yangi g'oya yoki misol qo'shish
- O'qishga qulayroq format berish

## Fayl formati

- Barcha maqolalar repo root katalogida saqlanadi.
- Yangi maqola nomi odatda `N-publish.md` ko'rinishda bo'ladi, masalan: `1-publish.md`, `2-publish.md`, `14-publish.md`.
- Fayl Markdown (`.md`) formatida bo'ladi.
- Mavzu sarlavhasi `## ...` bilan boshlanadi.
- Maqola oxirida navigatsiya linklari bo'lishi mumkin, masalan:

```md
[Home page](./index.md) | [Next page ->](./2-publish.md)
```

Yoki avvalgi sahifaga qaytish uchun:

```md
[<- Previous page](./1-publish.md) | [Home page](./index.md)
```

## Yangi maqola yozishda qaysi uslubni saqlash kerak?

- Matn aniq, tabiiy va o'qilishi qulay bo'lsin.
- Texnik bo'lmagan mavzularni ham yengil va tushunarli til bilan yoritib bering.
- Asosiy fikrni birinchi paragraflarda aniq ayting.
- O'zingizning tajriba, kuzatuv yoki qarashlaringizni ko'rsating, lekin asoslansin.
- Mavzu g'oyasini kengaytiradigan kichik punktlar yoki misollar qo'shishingiz mumkin.
- Maqola qisqa bo'lishi shart emas, lekin o'qishga qulay va foydali bo'lishi lozim.

## PR (Pull Request) qoidalari

1. O'zingizning filialingizda ishlang.
2. Fayl qo'shing yoki mavjud maqolani tahrirlang.
3. Faqat kerakli o'zgarishlarni kiriting; ortiqcha fayllar yoki noqulay ishlov berishlardan qoching.
4. PR sarlavhasi aniq bo'lsin, masalan:
   - `Add article: Doimiylik nega muhim?`
   - `Fix typo in 7-publish.md`
   - `Improve wording in article about networking`
5. PR ta'rifida nimani o'zgartirganingizni qisqacha yozing.

## Muhokama va takliflar

Agar fikr, savol yoki taklif bo'lsa, repo ichidagi [discussions](https://github.com/mnmbackend/git-blog/discussions) orqali yozishingiz mumkin.

## Litsenziya

## Muhim eslatma

- Yangi maqolani qo'shganingizda, avvalgi maqolalar bilan umumiy uslub va tuzilishga mos bo'lishiga e'tibor bering.
- Agar maqola raqamli nom bilan ishlatilayotgan bo'lsa, undan boshqa bo'sh `N-publish.md` raqamini tanlang.
- Barcha o'zgarishlarni mantiqiy, aniq va maqsadga yo'naltirilgan qilib qiling.

Tashakkur! Sizning hissangiz ushbu blogni yanada boyitadi.
