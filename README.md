# Git-Blog

Ushbu repozitoriyda shaxsiy blog va fikrlar to'plami saqlanadi. Asosiy maqsad — texnik bo'lmagan mavzularda kundalik fikrlar, tajriba, o'sish va hayotiy qarashlarni yozish.

## Repozitoriya haqida

Bu loyiha Markdown fayllar asosida qurilgan va GitHub orqali shunchaki statik sayt yoki blog ko'rinishida namoyish etiladi. Barcha maqolalar alohida `.md` fayllarda yoziladi va `index.md` orqali bosh sahifaga bog'lanadi.

## Fayllar tuzilmasi

- `index.md` — asosiy sahifa va maqolalar ro'yxati
- `-publish.md` — maqolalar fayllari
- `CONTRIBUTING.md` — hissa qo'shish bo'yicha ko'rsatmalar
- `LICENSE.md` — litsenziya
- `README.md` — loyiha haqida qisqacha ma'lumot

## Ko'rish usuli

Ushbu saytni ko'rish uchun quyidagilardan birini ishlatishingiz mumkin:

1. GitHub Repository sahifasida markdown fayllarni o'qing.
2. GitHub Pages yoki boshqa static hosting orqali `index.md` va maqolalarni render qiling.
3. Mahalliy mashinada Markdown ko'rish vositalaridan foydalaning.

## Hissa qo'shish

Agar maqolalarga o'zgartirish yoki yangi yozuv qo'shmoqchi bo'lsangiz, avval repozitoriyani fork qiling, o'zgartirishlarni kiritib, keyin pull request yuboring.

Batafsil ma'lumot uchun [CONTRIBUTING.md](./CONTRIBUTING.md) faylini o'qing.
